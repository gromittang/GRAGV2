# PM方案质量指标

## 阶段完成率

| 指标 | 计算方式 | 目标 |
|------|------|------|
| 确认率 | confirmed/sessions | ≥ 80% |
| 完成率 | P3完成/sessions | ≥ 60% |
| 回溯率 | rollback次数 | ≤ 20% |

## 内容质量

| 阶段 | 指标 |
|------|------|
| P0问题定义 | 目标明确、约束清晰 |
| P1方案分析 | 多方案对比、评分合理 |
| P2方案细化 | 功能完整、优先级清晰 |
| P3 PRD生成 | 结构完整、可执行 |

## 引用质量

| 指标 | 说明 |
|------|------|
| 来源数量 | 每阶段引用文档数 |
| 相关性 | 引用与阶段主题匹配 |
| 覆盖度 | 知识库利用率 |

## 响应时间

| 场景 | 目标 |
|------|------|
| 阶段对话 | < 5s (流式) |
| 确认生成 | < 3s |
| PRD导出 | < 1s |

## 用户满意度

- 标题准确度
- 结构化输出可用性
- 回溯体验

## 评估方法

- **用户反馈**: 每阶段确认后提供 1-5 星评分 + 满意度 toggle + 修改次数自动计数
- **反馈数据**: SQLite 存储（`pm_feedback.db`），GET /api/v1/pm-solution/feedback/stats 查看按阶段分组的统计
- **前端组件**: `StageFeedback.vue`，集成在 PMStudioPage 阶段内容区底部
