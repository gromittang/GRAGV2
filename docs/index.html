核心能力

三大模块协同：知识库 RAG 问答 + Data Copilot 数据查询 + PM 方案工作室，覆盖仓库日常工作的完整 AI 辅助链

🤖

Data Copilot

企业级 NL2SQL 数据智能助手。用户用自然语言提问，系统自动完成 Schema 语义检索 → SQL 生成 → 安全校验 → 执行 → AI 洞察分析的完整流水线。

语义层：覆盖库存、出库、拣货、配送、收货、商品、仓位、用户等 10+ 业务域，514 张表 / 7904 字段向量化索引。

🧠

智能问答

基于 RAG 的操作手册问答。Query 改写 + BM25 关键词检索 + 语义向量检索双路并行，RRF 融合 + bge-reranker 精排，结合 DeepSeek LLM 流式生成答案。

图片理解：文档中的图片自动提取并展示，AI 可结合图片内容回答。

📚

文档管理

支持 Word / PDF / TXT 文档上传和自动解析。图片自动提取并支持预览，文档按知识库分类隔离管理。支持批量操作、删除、重新索引。

中文优化：jieba 分词 + 2-4 字 n-gram，精准匹配仓库专业术语。

⚡

混合检索

LangGraph 编排的多阶段检索管线：Query 改写 → BM25 + 向量双路并行检索 → RRF 融合排序 → Cross-Encoder 重排序 → 相关性阈值过滤。

知识库隔离：每个知识库独立 ChromaDB 集合，互不干扰。

🎯

PM方案工作室

四阶段结构化方案设计：问题定义 → 方案分析 → 方案细化 → PRD 生成。每个阶段可独立确认、回溯、重新生成。

时间轴导航：顶部 TimelineStepper 替代传统步骤条，直观展示阶段进度与状态。

🔍

Schema 浏览器

可视化数据库表结构浏览器。支持关键词实时搜索 514 张表，点击表名弹出悬浮窗查看完整字段详情（类型、宽度、描述）。最多同时打开 5 个悬浮窗，可自由拖拽和调整大小。

📦 库存 🚚 出库 📥 收货/验收 🧺 拣货 🏍 配送 📋 商品信息 🏠 仓位 👤 用户 🔒 库存锁定 ⚙ 商品仓库设置
使用示例
用户问题： "本月良品仓有哪些商品库存不足100？"
生成SQL： SELECT s.plu_code, p.plu_name, SUM(s.stork_count) as total_stock FROM sto_stock_batch_yyyymm_org s JOIN cob_plu p ON s.plu_code = p.plu_code WHERE s.store_code = '01' AND p.is_active = 1 GROUP BY s.plu_code, p.plu_name HAVING SUM(s.stork_count) < 100 LIMIT 100
AI洞察： 当前良品仓共有 23 种商品库存低于 100，其中 5 种已接近零库存。建议优先补货：矿泉水(库存12)、纸巾(库存8)...

快速开始

三步部署，从零到拥有仓库智能知识库

1

Docker 启动

克隆项目，一键启动 Docker 容器

# 克隆项目
git clone https://github.com/gromittang/WMSRAGV2.git
cd WMSRAGV2

# 一键启动
docker-compose up -d
2

配置 API Key + MySQL

编辑环境变量，配置 LLM API 和业务数据库

# 编辑 backend/.env 文件
DEEPSEEK_API_KEY=your_api_key_here

# MySQL配置（Data Copilot 业务数据源）
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=your_password
MYSQL_DATABASE=wms

# LLM Provider（可选：deepseek/openai/anthropic）
LLM_PROVIDER=deepseek
3

访问系统

打开浏览器，开始使用三大模块

# 访问前端界面
http://localhost:8812

# Data Copilot:  /query     自然语言查数据
# 智能问答:      /chat      知识库 RAG 对话
# PM工作室:      /pm-studio  方案设计四阶段
# 知识库管理:    /knowledge  文档上传与索引
# 系统设置:      /settings   模型与连接配置

API 参考

核心接口前缀 /api/v1，默认端口 8812，共 12 个 Data Copilot 端点

方法 路径 说明
POST /api/v1/query/ 完整 NL2SQL 流水线（NL → SQL → 执行 → Insight）
POST /api/v1/query/execute 直接执行 SQL（带安全校验 + 自动 LIMIT）
GET /api/v1/query/schema 获取完整数据库 Schema（514 表）
GET /api/v1/query/schema/search 关键词搜索表/字段（SchemaBrowser 搜索框）
GET /api/v1/query/schema/table/{name}/fields 获取表字段详情（悬浮窗展示）
GET /api/v1/query/test-connection 测试 MySQL 连接状态
GET /api/v1/query/preview/{table} 预览表数据前 N 行
POST /api/v1/query/insight 为已有查询结果重新生成 AI 分析
GET /api/v1/query/history/{session_id} 获取会话查询历史
POST /api/v1/query/history/{session_id} 保存查询历史记录
GET /api/v1/docs 获取文档列表（按知识库分类）
POST /api/v1/docs/upload 上传文档（Word / PDF / TXT，最大 10MB）
POST /api/v1/chat/stream SSE 流式智能问答（Markdown 渲染 + 图片展示）
POST /api/v1/pm-solution/sessions 创建 PM 方案会话
GET /health 健康检查
