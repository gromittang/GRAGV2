Data Copilot

企业级 NL2SQL 数据智能助手。用户直接问"本月入库单有多少"，系统自动生成SQL执行，并提供AI业务洞察分析。

三层架构：Schema检索 → SQL生成 → 安全校验 → AI分析

🧠

智能问答

基于 RAG 的操作手册问答，支持图片理解。用户提问后，系统自动检索相关文档段落，结合 DeepSeek LLM 生成准确答案，并展示参考来源。

📚

文档管理

支持 Word/PDF/TXT 文档上传和自动解析，图片自动提取并预览。文档按知识库分类管理，支持批量操作、删除、重新索引。

⚡

混合检索

BM25 关键词检索 + 语义向量检索双重检索，RRF 融合排序。中文优化：自动提取 2-4 字 n-gram，精准匹配仓库专业术语。

🎯

PM方案工作室

支持产品经理完成"问题诊断 → 方案对比 → 方案细化 → PRD生成"完整链路。内置智能 BM25 搜索，快速定位相关需求文档。

💡

AI洞察分析

查询结果自动生成业务洞察：关键结论、异常点检测、趋势判断、建议行动。让数据变成决策依据，而非枯燥表格。

快速开始

三步部署，从零到拥有仓库智能知识库

1

Docker 启动

克隆项目，一键启动 Docker 容器

# 克隆项目
git clone https://github.com/gromittang/WMSRAGV2.git
cd WMSRAGV2

# 一键启动
docker-compose up -d
2

配置 API Key + MySQL

编辑环境变量，配置 DeepSeek API 和数据库

# 编辑 backend/.env 文件
DEEPSEEK_API_KEY=your_api_key_here

# MySQL配置（Data Copilot）
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=your_password
MYSQL_DATABASE=wms
3

访问系统

打开浏览器，开始使用知识库和Data Copilot

# 访问前端界面
http://localhost:8812

# Data Copilot: /query 路径
# 智能问答: /chat 路径
# PM工作室: /pm 路径

API 参考

核心接口前缀 /api/v1，默认端口 8812

方法 路径 说明
POST /api/v1/query/ 自然语言查询（NL→SQL→结果→Insight）
POST /api/v1/query/execute 直接执行SQL（带安全校验）
GET /api/v1/query/schema 获取数据库Schema（514表）
POST /api/v1/query/insight 为查询结果生成AI分析
GET /api/v1/docs 获取文档列表
POST /api/v1/docs/upload 上传文档（支持 Word/PDF/TXT）
POST /api/v1/chat/stream SSE流式智能问答
POST /api/v1/pm-solution/sessions 创建PM方案会话
GET /health 健康检查
