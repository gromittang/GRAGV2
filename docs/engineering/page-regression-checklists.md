# 页面回归检查清单（page-regression-checklists）

> 作用：用于前端改版后的页面级回归检查。
> 使用方式：当改动涉及核心页面（Query / Chat / Knowledge / PM / Settings / Logs）时，Claude 必须参考本文件，在 receipt 或输出中说明已检查项 / 待人工验证项。

---

# 0. 通用冒烟检查（所有页面都适用）

## 页面可用性

* [ ] 页面可以正常打开，无白屏
* [ ] 控制台没有明显报错 / 未处理异常
* [ ] 页面首屏布局没有明显错位、遮挡、溢出
* [ ] 在空数据 / 默认状态下页面能正常展示

## 基础交互

* [ ] 页面主按钮可点击
* [ ] 输入框 / 下拉 / 弹窗 / 抽屉等基础控件能正常工作
* [ ] loading / empty / error 状态至少不会让页面崩掉
* [ ] 路由跳转、返回、切页等基本行为正常

## 回归底线

* [ ] 原来能用的核心功能仍然可用
* [ ] 没有因为 UI 改版引入明显的 API 行为变化
* [ ] 没有明显样式污染到无关页面

---

# 1. Query / 数据查询 / NL2SQL 页面

## 主流程

* [ ] 用户输入自然语言问题后，可以正常触发查询
* [ ] 查询进行中有清晰的 loading 状态
* [ ] 查询成功后，SQL 展示区能正常显示
* [ ] 查询成功后，结果表格能正常显示
* [ ] 查询失败时有错误提示，且页面不会整体崩溃
* [ ] 查询返回空结果时，有合理的 empty 状态

## 页面结构与交互

* [ ] 查询输入区仍然是页面的主视觉焦点
* [ ] SQL 展示区、结果区、辅助区（如推荐问题）层级清晰
* [ ] 如果有推荐问题 / 示例问题，点击后行为正常
* [ ] 如果有“重新查询 / 清空 / 复制 SQL / 折叠展开”等操作，行为正常
* [ ] 表格在列较多 / 数据较长时不会明显挤坏布局

## 回归风险点

* [ ] UI 改版没有改坏原有的查询触发逻辑
* [ ] SQL 展示区与结果区的数据绑定仍然正确
* [ ] loading / error / empty / success 四类状态切换正常

---

# 2. Chat / 智能问答页面

## 主流程

* [ ] 输入问题后可以正常发送
* [ ] 发送后有清晰的 loading / thinking 状态
* [ ] 返回回答后消息能正常展示
* [ ] 回答失败时有错误提示，不会导致整个页面失效
* [ ] 清空会话 / 新建会话（如果有）行为正常

## 消息展示与布局

* [ ] 用户消息 / AI 消息的层级、样式、间距正常
* [ ] 长回答不会明显撑坏布局
* [ ] 如果有引用资料 / 来源信息 / 工具调用信息，显示正常
* [ ] 页面滚动、定位到最新消息等行为正常（如果有）

## 回归风险点

* [ ] UI 改版没有影响消息发送主流程
* [ ] 历史消息、会话切换、输入框状态管理仍然正常
* [ ] loading / error / empty / success 状态切换正常

---

# 3. Knowledge / 知识库页面

## 主流程

* [ ] 知识库列表 / 知识库详情能正常展示
* [ ] 如果支持上传、删除、重建索引、查看文档等操作，入口仍可用
* [ ] 空知识库 / 无文档 / 加载失败等状态能正常展示

## 页面结构与交互

* [ ] 列表区、详情区、操作区层级清晰
* [ ] 批量操作、筛选、搜索等入口（如果有）可正常使用
* [ ] 弹窗 / 抽屉 / 表单打开关闭正常

## 回归风险点

* [ ] UI 改版没有破坏知识库管理主流程
* [ ] 状态展示（处理中 / 成功 / 失败）仍然清楚
* [ ] 无文档 / 多文档 / 长文档名等情况布局正常

---

# 4. PM Workspace 页面

## 主流程

* [ ] 工作台首页可正常打开
* [ ] 新建 / 打开 / 编辑 / 删除草稿或工作项（如果有）入口正常
* [ ] 历史记录 / 卡片列表 / 内容面板能正常展示

## 页面结构与交互

* [ ] 主工作区是视觉重点
* [ ] 侧边栏 / 列表区 / 编辑区 / 辅助信息区层级合理
* [ ] 空状态、首次使用状态、加载状态合理
* [ ] 表单、弹窗、操作按钮行为正常

## 回归风险点

* [ ] UI 改版没有影响工作台主流程
* [ ] 历史记录切换、草稿打开、保存等交互仍然可用
* [ ] 多卡片 / 长文本 / 空状态下布局仍稳定

---

# 5. Settings / 设置页面

## 主流程

* [ ] 设置项列表能正常展示
* [ ] 保存 / 重置 / 测试连接等操作（如果有）可正常使用
* [ ] 校验错误 / 保存成功 / 保存失败等状态有明确反馈

## 回归风险点

* [ ] UI 改版没有改坏表单绑定与提交
* [ ] 必填项 / 默认值 / 切换项状态仍然正确

---

# 6. Logs / 日志页面

## 主流程

* [ ] 日志列表可正常展示
* [ ] 筛选 / 搜索 / 刷新 / 分页（如果有）可正常使用
* [ ] 空日志 / 加载失败 / 长文本日志展示正常

## 回归风险点

* [ ] UI 改版没有改坏日志筛选和刷新逻辑
* [ ] 长日志 / 大量日志时布局不明显崩坏

# 7. Receipt 中建议引用的写法

当 Claude 在 receipt 中引用本清单时，建议写成：

## 已检查项

* Query 页面：主流程、loading / error / empty / success 状态切换、SQL 展示区与结果区显示
* Chat 页面：消息发送、消息展示、长回答布局、错误状态

## 待人工验证项

* Query 页面：窄屏下表格横向滚动体验
* Chat 页面：超长回答 + 来源信息同时出现时的布局表现
